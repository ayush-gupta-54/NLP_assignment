# Rule-Based Medical Chatbot using NLP

This project is a rule-based medical chatbot built using Python and NLTK.

## Features
- Symptom-based disease identification
- Disease description
- Precaution suggestions
- Rule-based NLP chatbot

## Dataset
Disease Symptom Prediction Dataset (Kaggle) : 
https://www.kaggle.com/datasets/itachi9604/disease-symptom-description-dataset

## Tech Stack
- Python
- Pandas
- NLTK

## Run
```bash
python chatbot.py
